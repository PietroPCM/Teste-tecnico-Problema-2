# Problema 2
Crie uma classe `Aluno` com os seguintes atributos:

- `nome`
- `idade`
- `nota`

Instancie **5 alunos**, atribuindo valores diferentes para cada um.

Adicione esses alunos a uma lista e processe essa lista para:

1. Imprimir o nome de cada aluno.
2. Calcular e imprimir a média das notas dos alunos.
3. Encontrar e imprimir o nome e a nota do aluno com a maior nota.
4. Encontrar e imprimir o nome e a nota do aluno com a menor nota.
5. Ordenar os alunos pela nota, em ordem decrescente, e imprimir os nomes e notas nessa ordem.

#Como Rodar o Programa

Clonar o repositorio da url https://github.com/PietroPCM/Teste-tecnico-Problema-2 rodar javac Main.java no terminal com o caminho do arquivo Main.java em seguida rodar java Main no terminal para executar o programa.
